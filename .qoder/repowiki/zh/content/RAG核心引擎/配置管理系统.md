## 简介
本配置管理系统基于 YAML 配置文件与 Pydantic 类型验证，结合环境变量替换与单例模式，提供类型安全、可扩展且易于维护的配置能力。系统支持：
- 配置文件层次结构与默认值
- 环境变量注入与回退机制（${VAR} 与 ${VAR:-默认值}）
- 运行时配置热更新（通过强制重新加载）
- 组件间配置绑定与影响范围
- 审计日志开关与配置联动
- **新增**：认证系统配置、用户管理、Reranker配置选项、UI定制改进
- **新增**：API密钥安全管理、本地模型缓存、安装时自动配置
- **新增**：增强的本地模型检测功能，支持扁平目录和HuggingFace缓存布局
- **新增**：版本跟踪支持，实现应用版本统一管理
- **更新**：`load_config()` 函数实现优化，利用 Pydantic 内置序列化能力

## 项目结构
配置相关的核心文件与职责如下：
- 配置文件：config.yaml（顶层 YAML 配置，包含环境变量占位符）

## 核心组件
- **配置模型层（Pydantic）**：定义各子系统的配置结构、默认值与约束（如数值范围、枚举、字段间校验）。
- **环境变量替换**：支持 ${VAR} 与 ${VAR:-默认值} 两种语法，递归替换字典中的字符串值。
- **单例与加载**：提供 get_config()/reload_config()，确保全局唯一配置实例；from_yaml() 支持从文件加载并自动替换环境变量。
- **组件绑定**：UI 主题、日志与审计、向量库、预加载、RAG链路、文档加载、认证系统等均从全局配置读取关键参数。
- **认证系统**：新增用户认证配置，支持用户注册、登录、密码管理、角色权限控制。
- **Reranker配置**：增强的重排序模型配置，支持启用/禁用和Top-N控制，提升检索质量。
- **UI定制**：新增公司链接显示功能，支持企业级定制。
- **配置序列化优化**：`load_config()` 函数通过 Pydantic 内置 `model_dump()` 方法实现，提升代码简洁性。
- **本地模型检测**：新增 `detect_local_models()` 函数，支持扁平目录和HuggingFace缓存两种模型布局，自动设置环境变量。
- **版本跟踪**：通过 `__version__` 变量和 `config.yaml` 中的版本号实现统一的版本管理。

### 配置文件结构与层次
- **顶层键**包括：model_root、llm、embedding、reranker、vectorstore、knowledge、rate_limit、auth、ui、max_conversation_turns、audit_enabled、admin_users、version 等。
- **子模块键**：
  - **llm**：api_base、api_key（**已迁移到环境变量**）、model、temperature、max_tokens、context_window
  - **embedding**：model、local_path（支持环境变量覆盖）
  - **reranker**：model、local_path（支持环境变量覆盖，**新增**）、enabled（**新增**）、top_n（**新增**）
  - **vectorstore**：persist_directory、collection_name、top_k、distance_threshold
  - **knowledge**：docs_directory、chunk_size、chunk_overlap
  - **auth**：enabled（**新增**）、users_file（**新增**）、min_password_length（**新增**）、admin_users（**新增**）
  - **ui**：title、subtitle、company_name、company_url（**新增**）、logo_text、default_theme
  - **version**：应用版本号（**新增**）
  - **其他**：max_conversation_turns、audit_enabled、admin_users

**新增**：API密钥管理从config.yaml迁移到环境变量，提升安全性。新增${ENV_VAR:-default}语法支持，增强配置灵活性。新增认证系统配置和Reranker配置选项。新增版本跟踪支持，通过 `version` 字段实现。

默认值与约束来源于 Pydantic 模型定义，例如：
- llm.temperature ∈ [0.0, 2.0]，max_tokens ∈ [1, 128000]，context_window ∈ [1024, 256000]
- knowledge.chunk_overlap < knowledge.chunk_size
- vectorstore.top_k ≥ 1，distance_threshold ≥ 0
- ui.default_theme ∈ {"dark","light"}
- **新增**：reranker.model默认"BAAI/bge-reranker-base"，支持local_path离线加载，enabled默认True，top_n默认10
- **新增**：auth.enabled默认True，min_password_length默认4，users_file默认"./data/users.json"
- **新增**：version默认"0.18.18"，表示当前应用版本

### 本地模型检测功能
**新增** 增强的本地模型检测功能，支持两种模型布局：

- **扁平目录布局**：`model/text2vec-base-chinese/`、`model/bge-reranker-base/`
- **HuggingFace缓存布局**：`model/models--*--*/snapshots/<hash>/`

检测逻辑：
1. **优先级**：扁平目录 > HF缓存最新snapshot
2. **校验**：目标目录必须包含 `config.json` 和模型权重文件
3. **权重文件检测**：支持 `pytorch_model.bin`、`model.safetensors`、`tf_model.h5`
4. **幂等调用**：已有环境变量时不覆盖

```mermaid
flowchart TD
Start(["detect_local_models()"]) --> CheckRoot["检查 MODEL_ROOT 环境变量"]
CheckRoot --> ResolvePath["解析绝对路径"]
ResolvePath --> EmbCheck{"检测 Embedding 模型"}
EmbCheck --> FlatEmb["扁平目录检测"]
FlatEmb --> HFEmb["HF缓存检测"]
HFEmb --> EmbFound{"找到有效模型？"}
```

### 版本跟踪配置示例
**新增** 版本号获取机制：

```python
def _get_version() -> str:
    """从 config.yaml 读取版本号，读取失败时回退到硬编码默认值。"""
    try:
        import yaml
        from pathlib import Path
        config_path = Path(__file__).resolve().parent.parent / "config.yaml"
        if config_path.exists():
            with open(config_path, "r", encoding="utf-8") as f:
                config = yaml.safe_load(f) or {}
            return config.get("version", "0.8.17")
    except Exception:
        pass
    return "0.8.17"
```
